# Recipe Search

A Preact-based recipe search application that allows users to search
for recipes and view recipe information through a clean, responsive
interface. The application uses TheMealDB API to retrieve recipe data
dynamically based on user searches.

## Features

- Search for recipes by name
- Fetch recipe data dynamically from TheMealDB API
- Display recipe information, including title, description, image,
  category, and cuisine
- Display loading feedback while fetching recipes
- Show a message when no recipes match the search
- Display user-friendly error messages when a request fails
- Validate empty search submissions
- Use reusable components to organize the interface

## Technologies Used

- Preact
- JavaScript
- HTML
- CSS
- Vite
- TheMealDB API
- Git & GitHub
