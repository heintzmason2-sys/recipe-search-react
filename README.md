# Recipe Search

A React-based recipe search application that allows users to search for recipes and view recipe results through a clean, responsive interface.

## Features

* Search for recipes
* Display recipe results dynamically
* View recipe information
* React component-based structure
* Responsive user interface

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite
* Git & GitHub

## Getting Started

### Installation

Clone the repository:

```bash
git clone git@github.com:heintzmason2-sys/recipe-search-react.git
```

Navigate into the project:

```bash
cd recipe-search
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development server provided by Vite.
